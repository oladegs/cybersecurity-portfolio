# Cybersecurity Portfolio

## Overview

This portfolio contains cybersecurity projects focused on web application security testing, vulnerability assessment, discovery, fingerprinting, binary security research, and technical documentation.

The projects demonstrate hands-on security analysis skills aligned with cybersecurity analyst, SOC analyst, vulnerability analyst, cloud security, and security operations roles.

## Certifications

These certifications support my foundation in cybersecurity principles, risk management, network security, access control, cloud fundamentals, threat detection, and security best practices.

## Portfolio Projects

### 1. LOCO — x86 Code Obfuscation & Binary Security Analysis

Analyzed an x86 code obfuscation and de-obfuscation toolkit used for binary protection, reverse engineering resistance, control-flow graph analysis, and software protection research.

**Skills:** binary security research, reverse engineering concepts, malware analysis awareness, code obfuscation, technical documentation.

### 2. Web Application Authentication & Command Injection Testing

Assessed authentication weaknesses and command injection risks in a controlled DVWA environment, focusing on brute-force exposure, input validation, and remediation strategies.

**Skills:** authentication testing, brute-force analysis, command injection testing, input validation, vulnerability assessment.

### 3. Web Application XSS, CSRF & File Inclusion Testing

Tested common web application vulnerabilities including Stored XSS, CSRF, and file inclusion to understand insecure input handling, weak request validation, and unauthorized resource access.

**Skills:** XSS analysis, CSRF analysis, file inclusion testing, HTTP request behaviour, secure coding awareness.

### 4. Security Assessment, Fingerprinting & Nmap Scanning

Performed discovery and fingerprinting using Telnet, Nmap, and Zenmap to identify open ports, HTTP headers, service versions, and server details useful for security triage.

**Skills:** Nmap scanning, port scanning, service enumeration, fingerprinting, vulnerability assessment support.
