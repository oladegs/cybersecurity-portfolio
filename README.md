# Cybersecurity Portfolio

This portfolio contains hands-on cybersecurity projects focused on web application security testing, vulnerability analysis, discovery, fingerprinting, scanning, binary security research, and technical documentation.

The projects were completed in controlled lab environments and are intended to demonstrate practical security analysis skills, including identifying vulnerabilities, understanding attack behaviour, documenting findings, and recommending remediation steps.

## Projects

### 1. x86 Code Obfuscation & Binary Security Analysis
Analyzed LOCO, an x86 code obfuscation and de-obfuscation toolkit, with a focus on binary protection, control-flow graph analysis, reverse engineering resistance, and software protection techniques.

### 2. Web Application Authentication & Command Injection Testing
Assessed authentication weaknesses and command injection risks in a controlled DVWA environment, focusing on brute-force exposure, input validation, and mitigation strategies.

### 3. Web Application XSS, CSRF & File Inclusion Testing
Tested common web application vulnerabilities including Stored XSS, CSRF, and file inclusion to understand how insecure input handling and weak request validation can expose applications to risk.

### 4. Security Assessment, Fingerprinting & Nmap Scanning
Performed discovery and fingerprinting activities using Telnet, Nmap, and Zenmap to identify open ports, service versions, HTTP headers, and server details useful for security triage.
